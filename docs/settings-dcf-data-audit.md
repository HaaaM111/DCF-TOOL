# 终端设置与估值数据复核

复核样本：科博达（603786.SH）。设置模块的「数据与估值诊断」只读查询数据源和已发布底稿，不会保存财报、刷新生产标的档案或重发估值。

| 复核项 | 结果 |
| --- | --- |
| 工作簿原口径 | 35.758439 元/股 |
| 工作簿归母口径 | 35.535639 元/股；与线上已发布主估值一致 |
| 模型内部勾稽 | FCFF、ReOI、AOIG 最大每股差额约 4.5×10⁻¹⁵ 元 |
| 独立折现复核 | 将显性期 FCFF 和稳态 FCFF 终值逐项折现，与系统经营价值一致 |
| 估值时点 | 2025-12-31；报告和部分预测资料当时尚不可得，继续抑制同日上行空间 |
| 终值 | 现值约占经营价值 90.53%；对 WACC、长期增速和稳态经营回报较敏感 |
| 现金流字段 | 2025 年报：线上 iFinD 路由显示 CFO 5.47、Capex 3.74 亿元；东财同报告期分别为 5.468055749、3.735943494 亿元 |
| 行情日期 | 科博达东财快照曾返回 0 时间戳；改用可核验的不复权日线时取得 2026-11-20 收盘价 35.30 元 |

三种估值公式采用同一组经营假设。数值勾稽通过只证明实现与口径一致，不证明预测经营利润、再投资、稳态回报或 WACC 正确。当前默认财务链路使用年报，不能代替最新季报核对。报表报告期和市场报价时间分别记录，不把它们自动当成同一估值时点。港股财务没有东财 A 股财务接口兜底。

本轮修复：旧行情不再贴上请求日期；iFinD 日线使用原始币种和不复权口径；东财按返回的证券代码和报告期匹配主表，并要求资产负债表、现金流量表返回匹配的报告期。归母指标缺失时不再以合并净利润或净资产替代。关键缺项会阻止一键填表，部分非关键缺项保留原输入并提示。生产库中的已发布估值没有改写。
