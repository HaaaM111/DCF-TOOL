# 估值校验与研究参考

公司报告的经营估值接受带基期、资料可得日、预测年度和权益桥接的输入。确定性引擎从税后经营利润和净经营资产推导 FCFF、ReOI 和 AOIG。服务端使用同一底稿计算基准、敏感性与模拟，页面显示返回的结果。已有分红修正 DCF 仍可用于原有的估值和跳跃压力情景。

## 主估值与版本

底稿先复算，通过三模型勾稽后可从公司报告发布。发布请求校验证券代码和当前版本，服务端按原始输入重算，并在同一事务中保存不可变底稿和更新当前版本。相同输入重复提交会返回同一版本。旧页面再次发布之前需要重新加载当前底稿。

看板、公司报告、估值验证与智能体读取同一已发布版本。估值锚点及资料截止日随版本保存。事后复算只显示该口径每股值。与市价或同行的横向差异需同时满足日期、币种及有效样本条件。估值导出包含当前经营底稿，可从另一设备的报告页重新导入与发布。

缺少货币资金时，数据适配层保留缺失状态，并尝试读取同报告期 A 股资产负债表。表单保留已编辑的预测假设。存量记录如呈现零现金、有息负债且未作净现金调整，或净现金无法勾稽，主估值标为待核验。可取得的简化估值保留参考标签。账面货币资金、受限资金和用于股权桥接的非经营现金应逐项核对。

## 报表和分部预测

预览、发布和历史版本读取经过同一套输入校验。可提供 `openingBalance`，明确区分经营资产负债和金融资产负债，系统推导期初 NOA 和 NFO，并与归母净资产、少数股东权益账面值勾稽。估值使用的少数股东权益作为独立的股权桥接输入，可以采用与账面值不同的经济价值。

可提供 `forecastDrivers`，按年记录分部收入、税后经营利润率、其他税后经营损益及资产周转率。每年的税后经营利润是各分部收入乘税后经营利润率之和加其他损益，期末 NOA 是合计收入除以资产周转率。系统随后计算净再投资、FCFF、ReOI 和 AOIG。提供驱动数据后可省略已派生的汇总字段。若同时提供汇总值，系统拒绝与报表或驱动计算不一致的输入。

该路径借鉴 Financial Modeling Agent 的财报映射、预测驱动与确定性计算分层，以及 Forma 的跨报表情景一致性。现有直接输入年度经营利润与 NOA 的底稿可继续读取及复算。

## 情景模型

| 环节 | 经营口径 | Excel 复算口径 |
| --- | --- | --- |
| WACC 与永续增长率热力图 | 用每格 WACC 重算资本费用和现值 | 固定基准 WACC 计算的 ReOI，替换折现率和永续增长率 |
| 蒙特卡洛 | 对 WACC 与永续增长率抽样。项目收入按标准三角分布抽样，并经税后利润率和资产周转率调整经营利润和 NOA | 重现表中的两次均匀抽样分支，收入冲击乘税后利润率，累加到起始年及以后各期 ReOI |
| 永续约束 | 每个模拟把增长率限制在抽样 WACC 减最小利差，回传触发上限和剔除次数 | 同左 |

两种模拟共用种子和利率抽样。Excel 复算模式复现抽样方法，已保存抽样逐笔复放才对应原表 P5/P50/P95。蒙特卡洛区间反映设定的参数分布。基期与报价跨日或使用事后资料时，市价比较和隐含增长率停用。

## 同行比较

报告与估值智能体调用同一同行服务。科博达用汽车电子业务相关的德赛西威、华阳集团和均胜电子。其他 A 股标的按已记录的细分行业精确匹配。同行使用同一收盘日、不复权 A 股收盘价、同一年度报告及人民币口径。北京时间 15:00 前使用最近已收盘的日线。市值按 A 股收盘价乘年报总股本估算，双重上市公司存在价差，股本变动后也需要复核。PE 使用归母净利润，PB 使用归母净资产，PS 使用营业收入。每种倍数需三家有效同行，估值以中位数为主。缺少归母口径、净现金或其他所需字段时显示数据不足。

底稿中的 EV/次年税后经营利润与 EV/基期 NOA 使用明确的市值日、资料日期和同行名单，可选中位数折价。这两个倍数按经营价值桥接回股权价值。导入文件中的同行说明由使用者提供。

| [Financial Modeling Agent](https://github.com/Ocisly14/financial_modeling_agent) | 借鉴财报、假设、计算与敏感性分层。模型和 API 保留为 TypeScript，智能体消费确定性工具结果。 |
| [OpenBB Platform](https://docs.openbb.co/odp/python/concepts/extensions) | 借鉴数据提供方适配与统一输出，让页面和智能体共享同行数据核验。 |

## 本地验证

运行 `npm test` 和 `npm run build`。进入公司报告，展开「经营价值勾稽」，填入虚拟示例或导入底稿后点击「复算并校验」。在热力图中切换经营口径和 Excel 复算，使用带模拟参数的底稿检查 P5、P50、P95。配置可用行情与年报数据源后，在 PE/PB/PS 区查看同行及来源。
