# 估值校验与研究参考

公司报告的经营估值接受带基期、资料可得日、预测年度和权益桥接的输入。确定性引擎从税后经营利润和净经营资产推导 FCFF、ReOI 和 AOIG。服务端使用同一底稿计算基准、敏感性与模拟，页面显示返回的结果。已有分红修正 DCF 仍可用于原有的估值和跳跃压力情景。

## 主估值与版本

底稿先复算，通过三模型勾稽后可从公司报告发布。发布请求校验证券代码和当前版本，服务端按原始输入重算，并在同一事务中保存不可变底稿和更新当前版本。相同输入重复提交会返回同一版本。旧页面再次发布之前需要重新加载当前底稿。

看板、公司报告、估值验证与智能体读取同一已发布版本。估值锚点及资料截止日随版本保存。事后复算只显示该口径每股值。与市价或同行的横向差异需同时满足日期、币种及有效样本条件。估值导出包含当前经营底稿，可从另一设备的报告页重新导入与发布。

缺少货币资金时，数据适配层保留缺失状态，并尝试读取同报告期 A 股资产负债表。表单保留已编辑的预测假设。存量记录如呈现零现金、有息负债且未作净现金调整，或净现金无法勾稽，主估值标为待核验。可取得的简化估值保留参考标签。账面货币资金、受限资金和用于股权桥接的非经营现金应逐项核对。

## 报表和分部预测

预览、发布和历史版本读取经过同一套输入校验。可提供 `openingBalance`，明确区分经营资产负债和金融资产负债，系统推导期初 NOA 和 NFO，并与归母净资产、少数股东权益账面值勾稽。估值使用的少数股东权益作为独立的股权桥接输入，可以采用与账面值不同的经济价值。

可提供 `forecastDrivers`，按年记录分部收入、税后经营利润率、其他税后经营损益及资产周转率。每年的税后经营利润是各分部收入乘税后经营利润率之和加其他损益，期末 NOA 是合计收入除以资产周转率。系统随后计算净再投资、FCFF、ReOI 和 AOIG。提供驱动数据后可省略已派生的汇总字段。若同时提供汇总值，系统拒绝与报表或驱动计算不一致的输入。

该路径借鉴 Financial Modeling Agent 的财报映射、预测驱动与确定性计算分层，以及 Forma 的跨报表情景一致性。现有直接输入年度经营利润与 NOA 的底稿可继续读取及复算。

## 情景模型

- 敏感性按每个情景的 WACC 重算资本费用与现值，网格基准采用已保存的 WACC 与永续增速。
- 蒙特卡洛按设定的分布抽样 WACC 和永续增长率。项目收入冲击经利润率和周转率进入经营利润和 NOA。模拟把增长率限制在抽样 WACC 减最小利差，并报告限幅和剔除次数。
- 旧版简化模型以 Ke 折现股东回报。逆向 Gordon 反推终局自由现金流，Exit PE 情景才反推终局净利润。两者的分母口径在视图中列明。
- 股价走势使用实际不复权日线。周、月按交易日聚合，开盘取首日、收盘取末日、最高和最低取区间极值。缺少开高低字段时显示真实收盘价。股价走势图与正式估值展示各自的时点。

## 同行比较

报告与估值智能体读取同一行业资料库。设置中的「行业估值资料」可按行业查看、更新、回查或下载快照。快照按行业、收盘日和年报期保存，记录原始分母、数据源、价格和剔除原因。科博达用汽车电子业务相关的德赛西威、华阳集团和均胜电子。其他 A 股标的按研究分组或工作区的细分行业匹配。

同一快照使用同一收盘日、不复权 A 股收盘价、同一年度报告及人民币口径。北京时间 15:00 前使用已收盘的日线。市值按 A 股收盘价乘年报总股本估算，双重上市公司存在价差，股本变动后也需要复核。P/E 使用归母净利润，P/B 使用归母净资产，P/S 使用营业收入。EV 为市值减可核验净现金的简化口径，金融业停用 EV 倍数。来自年报利润表的 EBIT 为利润总额加费用化利息，EBITDA 取有同报告期来源的补充指标。按个股计算相对估值时先剔除标的自身；每项至少需三家有效同行，以中位数为主，缺少字段或有效样本时显示数据不足。数据源取数失败时，标的和同行一同读取留存快照并展示原收盘日。

## 研究与项目

| 参考 | 采用的做法 |
| --- | --- |
| [FinForesight，2026 年 11 月预印本](https://arxiv.org/abs/2611.01621) | 公式误差与预测表现分别检验。保存可复放的参数样本，对照缓存的原表结果。 |
| [Investor’s Last Exam，2026 年 10 月预印本](https://arxiv.org/abs/2610.38342) | 把资料可得日、市场日期和估值锚点显式写入估值底稿，标注事后复算。 |
| [FinFIRST，2026 年 9 月预印本](https://arxiv.org/abs/2609.25192) | 对齐证券、币种、期间和定义，逐个展示同行筛选原因及行情与财务来源。 |
| [Forma，2026 年 8 月预印本](https://arxiv.org/abs/2608.11327) | 借鉴会计勾稽和场景一致性的思路，收入冲击同时影响经营利润和营运资产。 |
| [Nissim 与 Penman 的财务比率与权益估值研究](https://business.columbia.edu/faculty/research/ratio-analysis-and-equity-valuation-research-practice) | 从经营与融资分解出发，用经营资产、剩余经营收益及现金流交叉核对。 |
| [Damodaran 的估值示例](https://pages.stern.nyu.edu/~adamodar/pdfiles/eqnotes/dcfegs.pdf)与[可比倍数讲义](https://pages.stern.nyu.edu/adamodar/New_Home_Page/lectures/multintr.htm) | 对模型驱动因子抽样，用可比公司的估值中位数作主要口径。 |
| [Financial Modeling Agent](https://github.com/Ocisly14/financial_modeling_agent) | 借鉴财报、假设、计算与敏感性分层。模型和 API 保留为 TypeScript，智能体消费确定性工具结果。 |
| [OpenBB Platform](https://docs.openbb.co/odp/python/concepts/extensions) | 借鉴数据提供方适配与统一输出，让页面和智能体共享同行数据核验。 |

## 本地验证

运行 `npm test` 和 `npm run build`。进入公司报告，展开「经营价值勾稽」，填入虚拟示例或导入底稿后点击「复算并校验」。在详情页切换日 K、周 K、月 K，核对开高低收。在敏感性页核对基准格，使用带模拟参数的底稿检查 P5、P50、P95。配置可用行情与年报数据源后，在 PE/PB/PS 区查看同行及来源。
